## O que o sistema faz

- Cadastra a fórmula de um produto: cada componente, seu nível e quanto entra em uma unidade.
- Exibe a explosão completa do produto, do item final até as peças mais básicas.
- Recebe a quantidade a produzir e devolve a necessidade de cada componente.
- Calcula o valor de aquisição do lote com um clique.
- Atualiza o preço de um componente e propaga a mudança para todos os produtos que o utilizam.
- Mantém produtos, componentes e preços em um cadastro editável, com tela própria para cada operação.


## Tecnologias

- **Java** para a árvore, o cálculo e a API de cadastro
- **HTML** para a interface de cadastro e visualização
- **Testes automatizados** cobrindo explosão, implosão e atualização de preço
